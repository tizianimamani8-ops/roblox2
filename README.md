# BlockVerse — Landing Page

Landing page promocional estática con temática inspirada en videojuegos de bloques.

## Archivos

- `index.html` — estructura de la web.
- `style.css` — diseño responsive.
- `script.js` — interacción del FAQ.
- `PROMPT.txt` — prompt utilizado para generar la idea.

## Subir a GitHub Pages

1. Creá un repositorio en GitHub.
2. Subí `index.html`, `style.css` y `script.js`.
3. En GitHub, entrá a **Settings → Pages**.
4. En **Build and deployment**, seleccioná la rama principal y la carpeta `/root`.
5. Guardá los cambios y GitHub Pages publicará la página.

## Personalización rápida

En `index.html` podés cambiar:
- `BlockVerse` por el nombre de tu proyecto.
- Los textos del evento.
- La URL de los botones que llevan a Roblox.
- Las recompensas y estadísticas.

La página es un proyecto promocional no oficial y no representa una página oficial de Roblox.
