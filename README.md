# BlockVerse — Landing Page V2

Página promocional estática con estética retro de videojuegos de bloques.

## Incluye

- Landing page responsive.
- Hero con animación GIF local.
- GIF wall con 3 GIFs originales incluidos en `media/`.
- Efecto 3D al mover el mouse sobre la tarjeta principal.
- Partículas de fondo.
- Barra ticker animada.
- Countdown.
- Sección de premios ampliada.
- FAQ desplegable.
- Mini-juego de atrapar cubos usando teclado o mouse.
- Récord guardado en `localStorage`.
- Sin backend.

## Archivos

- `index.html`
- `style.css`
- `script.js`
- `media/neon-cube.gif`
- `media/block-jump.gif`
- `media/bonus-coin.gif`

## GitHub Pages

Subí todos estos archivos manteniendo la estructura de carpetas.

Después:
**Settings → Pages → Deploy from a branch → rama principal → `/ (root)` → Save**

## Cambiar el enlace del juego

Buscá `https://www.roblox.com/` dentro de `index.html` y reemplazalo por el enlace de tu experiencia.

## Importante sobre la marca

Esta plantilla no incluye el logotipo oficial ni una copia exacta de la tipografía de marca de Roblox. La identidad visual está hecha como una interpretación retro inspirada en videojuegos de bloques.
